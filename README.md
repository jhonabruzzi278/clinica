# Clinica Linda Sonrisa - Sitio Web Corporativo

## Descripcion del Proyecto
Desarrollamos el sitio web corporativo de **Clinica Linda Sonrisa** con enfoque en captacion de pacientes, confianza de marca y conversion directa.
La plataforma presenta los servicios clave de la clinica, testimonios reales y canales de contacto inmediato para transformar visitas en citas.

## El Desafio
La clinica necesitaba una presencia digital que no solo "se viera bien", sino que **vendiera**:
- Comunicar profesionalismo y cercania desde el primer segundo.
- Explicar tratamientos de forma clara para reducir dudas y friccion.
- Facilitar el contacto rapido (especialmente desde movil).
- Diferenciarse en un mercado local altamente competitivo.

## La Solucion
Disenamos e implementamos una web enfocada en conversion, con estructura clara y mensajes orientados al paciente:
- **Hero principal** con propuesta de valor y llamado a la accion.
- **Seccion de especialidades** para mostrar servicios de forma visual y comprensible.
- **Proceso dental** para transmitir transparencia y confianza.
- **Testimonios** para reforzar prueba social.
- **Boton de WhatsApp** para contacto inmediato y generacion de leads.
- **Paginas legales** (privacidad y terminos) para respaldo de marca y cumplimiento.

## Resultados
El proyecto entrega una base comercial solida para crecer digitalmente:
- Mayor claridad en la oferta de servicios.
- Mejor percepcion de marca profesional.
- Experiencia rapida y simple en desktop y movil.
- Canal directo de contacto para aumentar oportunidades de cita.
- Sitio preparado para escalar campanas de marketing y posicionamiento local.

## Tecnologias
- **Astro** para rendimiento y carga rapida.
- **Tailwind CSS** para una interfaz moderna y consistente.
- Arquitectura modular con componentes reutilizables.
- Recursos optimizados (imagenes WebP, estructura ligera).
- Base preparada para futuras integraciones analiticas y de marketing.

## Servicios
- Ortodoncia
- Implantes dentales
- Endodoncia
- Odontopediatria
- Limpieza dental
- Estetica dental

## Comandos de Desarrollo
Todos los comandos se ejecutan desde la raiz del proyecto:

| Comando           | Descripcion                                      |
| :---------------- | :----------------------------------------------- |
| `npm install`     | Instala las dependencias del proyecto            |
| `npm run dev`     | Inicia el entorno de desarrollo local            |
| `npm run build`   | Genera la version de produccion en `./dist/`     |
| `npm run preview` | Levanta una vista previa de la build de produccion |
